The portfolio is built with a refined, accessible **Light Theme** engineered for clarity, technical credibility, and optimal user experience across all devices.

---

## Technical Stack

- **Framework:** React 19 with TanStack Start & TanStack Router
- **Styling:** Tailwind CSS v4 with custom OKLCH color design tokens & modern CSS utilities
- **Components:** Radix UI Dialog primitives with full accessibility (ARIA, keyboard navigation, focus management)
- **Icons:** Lucide React
- **Build Tool:** Vite 8 with TypeScript 5.8
- **Testing:** Vitest & React Testing Library

## Running Locally

### Prerequisites
- Node.js (v18+)
- npm (v9+)

### Installation & Development

```bash
# Install dependencies
npm install

# Start the development server
npm run dev
```

Visit `http://localhost:3000` (or the port specified by Vite in the terminal output).

### Production Build & Verification

```bash
# Type check and build for production
npm run build

# Run unit tests
npm test

# Run ESLint
npm run lint
```
